Services & clés API

Les fournisseurs de recherche Web se configurent par variables d'environnement sur la machine qui fait tourner WebIntel. Aucune clé n'est saisie ni conservée en clair dans l'interface : définissez la variable, puis redémarrez l'application. Le statut ci-dessous indique seulement si la variable est présente au démarrage, jamais sa valeur.

Où définir les variables ?

Dans le fichier .env ou l'environnement du processus WebIntel, par exemple :
WEBINTEL_BRAVE_API_KEY=… (remplacez par votre clé, sans la partager). Sans clé, WebIntel utilise les fournisseurs disponibles et signale clairement ceux qui manquent — aucune recherche n'est présentée comme disponible hors-ligne.

Outils scientifiques (RDKit installé par défaut)

WebIntel fonctionne en mode CORE (léger) sans ces outils. RDKit (installé par défaut) débloque la chimoinformatique réelle (similarité structurelle, descripteurs moléculaires, docking). Sans eux, l'application indique explicitement ce qui n'est pas calculable — aucune valeur n'est jamais inventée.
